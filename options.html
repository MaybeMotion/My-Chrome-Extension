Your Mac. Your words. No API bills.

Rephrase runs locally with the Ollama app and Qwen 2.5 3B. No API key or subscription is needed. The model download is roughly 2 GB; speed depends on your Mac.

  1. Install Ollama for Mac ↗, then open it.
  2. Open Terminal and download the model. If you already have it, skip this step: ollama pull qwen2.5:3b
  3. Allow this extension to connect. Copy this command into Terminal: Open this page through the installed extension to see your command.
  4. Fully quit Ollama from its menu-bar icon and open it again. Keep it running while you use Rephrase.
Ready when you are. The first rewrite may take longer while the model loads.

Your text goes only to the Ollama app on this Mac when you choose a tone. Rephrase never calls OpenAI. If Chrome asks for local-network access, allow it for Rephrase. Setup is automatic; there’s nothing to enter or save.

Using Windows or Linux, or need help?

Install Ollama for your system and the same Qwen model. The included README explains how to allow this extension to connect on Windows and Linux. If the model loads slowly, run ollama run qwen2.5:3b first, then try again.
