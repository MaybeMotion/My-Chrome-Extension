Install or update

  1. Download and extract the ZIP to a permanent folder.
  2. Open chrome://extensions in Chrome, enable Developer mode, click Load unpacked, and choose the extracted folder containing manifest.json.
  3. If updating an existing installation, replace the files in its current folder and click Reload on its extension card. Otherwise disable the old copy to avoid duplicate panels. Reload Zoho and other website tabs.

Use the Ollama app

  1. Install Ollama for Mac, then open it.
  2. Open Terminal and download the model once. Skip this step if it is already installed:ollama pull qwen2.5:3b
  3. Open Rephrase from Chrome’s extension toolbar, then Open studio & settings. Copy the Mac permission command shown there into Terminal. The extension fills in its own ID automatically.
  4. Fully quit Ollama from its menu-bar icon, then reopen it. Keep it running while using Rephrase.
  5. Click Check local connection in the extension. Once ready, highlight text inside an email draft, choose a tone, and click Replace selection.

The panel stays open while scrolling and expands for longer text. The modern violet monogram is included. Selecting ordinary webpage text to copy never opens the panel; Rephrase appears only inside editable text fields and email drafts. Your selected text goes only to the Ollama app on your computer when you choose a tone.

Chrome 119 or newer. The initial Qwen model download is roughly 2 GB and needs internet; rewriting runs locally afterward. Automated tests use mocked model replies; live Ollama and Zoho use need checking on your computer. Full instructions are in README.md inside the ZIP.
